# LocalMind
1. Push this folder to a GitHub repo (branch `main`, Settings > Actions > Workflow permissions: Read and write).
2. Each push builds a Release with the Android APK and Windows .exe.
3. In the app: Model > paste a Hugging Face link > pick your Colab GPU > Generate.
4. Run the code in Colab (GPU runtime). Paste the printed Server URL + API key under Server.
